# Telegram Birthday Bot

Це простий Telegram-бот для привітань з днем народження, написаний на чистому PHP без сторонніх бібліотек.

## Що робить бот
- Відправляє початкове повідомлення після натискання /start
- Виводить інлайн-клавіатуру з цифрами 1-9
- Користувач вводить 4-значні коди на кожному етапі
- Якщо код правильний — рухається далі
- Якщо код неправильний — просить повторити
- В кінці надсилає привітання 🎉

## Як налаштувати
1. Завантажте файли на свій сервер.
2. Замініть `YOUR_BOT_TOKEN` у `index.php` на токен вашого бота.
3. Налаштуйте Webhook командою:

```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://yourdomain.com/index.php
```

4. Все готово!

## Файли
- `index.php` — основна логіка бота.
- `data.json` — збереження прогресу користувачів.
- `README.md` — інструкція.
